# dmobservait.com (site publicado)

Arquivos prontos do site da DM ObservaIT Soluções em Tecnologia LTDA, gerados pelo `build.mjs` do projeto do site
(pasta `dist/`). Não edite aqui: altere o código-fonte, rode o build e publique um novo commit.

O container `dm-observait-site` no VPS baixa este repositório **num commit fixo** (definido no docker-compose do projeto)
e o nginx serve os arquivos. Para atualizar o site: novo commit aqui e troca do commit no compose.

Este repositório contém só o site público: nenhum código-fonte, configuração privada, senha ou token.
